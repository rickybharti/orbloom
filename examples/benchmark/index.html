What the numbers mean

        

          

            
Frame pacing

            
Counts calls that actually render, then reports effective FPS and the slowest five percent of frame intervals.

          

          

            
CPU frame cost

            
Times the renderer’s JavaScript, WebGL command submission, and copy into the visible transparent canvas.

          

          

            
GPU frame cost

            
Uses asynchronous disjoint timer queries. Unsupported browsers report unavailable instead of guessing.

          

          

            
Long frames

            
Combines measured intervals with the browser’s Long Animation Frames API when that API is exposed.
